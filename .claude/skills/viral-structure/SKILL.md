# Structure rules (the only opinions in this repo)

## Short (15-60s)
- Hook lands in **frame 0** and is *spoken* before 0.9s. The thumbnail is frame 0 — it must already read.
- One idea per sentence. 2.5 words/second. 75 words ~ 30 seconds.
- Visual type must change every beat (the engine has 8 types; alternating is free variety).
- Body: a number, a comparison, a method — in that order. Evidence before advice.
- Loop: last line echoes the first line. The engine checks this in QA.

## Hook formulas (pick 3 different ones, let the human A/B)
| formula | template |
|---|---|
| `contrarian` | "Stop [common habit] if you want [result]." |
| `curiosity` | "The [thing] that [surprise] — and it isn't [obvious filler]." |
| `empathy` | "If your [metric] has been stuck at [number], watch this." |
| `number` | "I tested [N] [things]. [N-k] failed." |
| `interrupt` | "Your first [N] seconds are lying to you." |
| `steal` | "Steal the exact [asset] I used to [result]." |

## Long (8-12 min)
Cold open (0-15s, scene first) -> promise (15-45s) -> 6-10 chapters of 45-120s ->
re-hook every 60-90s (`rehook: true`) -> recap grid -> one open loop.

## Reject a script if
- it opens with "In this video", "Hey guys", or the channel name
- any claim has no data, no demo, or no source
- more than one CTA
- a sentence contains two ideas
- the on-screen text is a transcription of the voiceover
